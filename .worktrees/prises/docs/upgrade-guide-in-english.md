# docs/upgrade-guide-in-english

- **Work item**: `UPGRADE.md`, the guide a consumer follows when a release breaks something. It is
  the last French file outside `documentation/`, `.cursor/`, `openspec/` and the two supervised
  `bin/` scripts. 324 lines, French from top to bottom.
- **Entry points**: `UPGRADE.md` only. Prose, headings and the explanatory text around the code
  fences. Every fence stays byte-identical — the `before` / `after` snippets, the Rector
  invocations, the class and attribute names are what a reader copies.
- **State**: in progress.
