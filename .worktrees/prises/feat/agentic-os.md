# feat/agentic-os

- **Work item**: an agentic OS for this repository — the permanent layer of files, scripts and
  ledgers that lets a model work on the repo unattended and be checked while it does. Nine layers,
  after Linas Beliūnas' "How to Build an Agentic OS with Claude Fable 5" (2026-07-10), ported to
  this monorepo's PHP toolchain and to the `claude` CLI.
- **Entry points**: `CLAUDE.md` (new, the constitution), `loop/` (new, the heartbeat and its
  ledgers), `Makefile` (new, the ops verbs), `documentation/wa/WA007-…md` and the WA table in
  `documentation/INDEX.md`. Nothing under `src/`.
- **State**: in progress.
